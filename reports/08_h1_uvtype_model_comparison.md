# H1 가설 모델 비교: UV_type 효과는 Lot 교란을 통제하면 사라지는가

**질문**: UV_type(G/H/I)이 Target(결함수)에 독립적 효과가 있는가, 아니면 이전에 발견한
Lot-UV_type 교란구조("32개 Lot 중 13개는 UV_type을 하나만 씀")로 인한 착시인가?

**데이터**: 웨이퍼 단위 1,704행(die-행 15,390개를 그대로 쓰면 웨이퍼 하나가 ~9번
의사복제되어 표준오차가 인위적으로 줄어듦 — H2 가설에서 확인된 사실을 여기서도 적용).

서로 다른 5가지 접근법(단순~정교, 통계적~ML적)으로 같은 질문을 던지고 결론이
접근법에 무관하게 일관되는지 확인했다.

## 모델별 결과

| 모델 | Lot 통제 방식 | UV_type=H 계수 | p-value | R² | AIC |
|---|---|---|---|---|---|
| **A. 나이브 OLS** | 없음 (기존 착시 재현) | **+20.54** | **<0.0001 \*\*\*** | 0.020 | 19016.2 |
| **B. OLS + Lot 고정효과(32개 전체)** | 더미변수, 클러스터robust SE | −2.94 | 0.393 (n.s.) | 0.204 | 18725.3 |
| **C. OLS + Lot 고정효과(혼합 19개 Lot만)** | 더미변수, 단일-UV_type Lot 13개 제외 | −2.94 | 0.398 (n.s.) | 0.028 | 10795.9 |
| **D. 혼합효과모형(Lot 랜덤절편)** | 부분풀링(partial pooling) | −0.34 | 0.938 (n.s.) | — | — |

| ML 모델 (E) | CV R² (5-fold) |
|---|---|
| Lot_Num만 | 0.1485 ± 0.1073 |
| Lot_Num + UV_type | 0.1382 ± 0.1157 |
| **UV_type 추가 효과(ΔR²)** | **−0.0103** (오히려 하락) |
| UV_type permutation importance | 0.038 |
| Lot_Num permutation importance | 0.448 (UV_type의 약 12배) |

## 해석

1. **모델 A(나이브)**만 유의한 효과(+20.54, p<0.0001)를 보인다 — 이전 프로젝트에서
   처음 보고했던 "+20.1% H-line 효과"가 정확히 이 편향된 추정치였음을 재확인.
2. **Lot을 어떤 방식으로 통제하든(B/C/D — 고정효과 전체, 고정효과 혼합-Lot만, 랜덤절편)
   계수가 거의 동일하게 −2.94로 수렴하고, 전부 통계적으로 유의하지 않다**(p=0.39~0.51).
   부호까지 반전된다(양수→음수). 세 가지 완전히 다른 추정 방법이 같은 답에 수렴한다는 건
   우연이 아니라 실제로 UV_type의 독립 효과가 없다는 강한 증거.
3. **ML 모델(E)도 같은 결론**: Lot_Num을 이미 아는 상태에서 UV_type을 추가하면 CV R²가
   오히려 떨어진다(과적합성 노이즈 추가) — UV_type이 예측에 기여하는 정보가 Lot_Num이
   이미 가진 정보와 사실상 중복되거나 그보다 약하다는 뜻. permutation importance도
   Lot_Num이 UV_type보다 12배 크다.
4. **AIC**: 나이브(A, 19016) → Lot 고정효과(B, 18725)로 대폭 개선 — Target 변동의
   상당 부분이 UV_type이 아니라 Lot 자체(레시피 드리프트, 설비 상태 등 다른 Lot-레벨
   요인)에서 온다는 뜻.

## 강건성 검증 (파라미터/시드/옵티마이저를 바꿔가며 재확인)

최초 실행은 각 모델을 설정값 하나로 한 번씩만 돌린 것이었다. 이후 요청에 따라 아래
4가지를 바꿔가며 다시 검증했다.

**1) OLS(B) — 표준오차 추정방식 3종** (classical / HC3 이분산robust / cluster-robust):
계수는 −2.941로 고정(SE 추정방식은 계수 자체엔 영향 없음), p-value는 0.396~0.510 —
어떤 SE를 쓰든 "유의하지 않음" 결론 불변.

**2) MixedLM(D) — 최적화 알고리즘 4종** (lbfgs/cg/bfgs/powell): 여기서 실제 문제를
발견했다. 기본값 `lbfgs`는 "경계 해" 경고 5건(공분산행렬 특이, Hessian 비양정치)과 함께
coef=−2.94로 수렴했는데, `cg`/`bfgs`/`powell` 3개는 경고 없이 서로 정확히 일치하는
coef=−0.34, p=0.938로 수렴했다. 경고 없는 3개가 일치하므로 그쪽을 신뢰해 **표 D의
값을 −2.94→−0.34로 정정**했다(결론은 바뀌지 않음 — 오히려 더 확실하게 0에 가까워짐).

**3) LightGBM(E) — KFold 시드 20개 반복**: ΔR²가 seed에 따라 흔들릴 수 있다는 우려로
0~19 시드 20개로 재실행. 결과: **20/20 전부 음수**(mean=−0.0065, std=0.0029,
범위 −0.0123~−0.0000) — 단 한 번도 UV_type 추가가 도움된 적이 없다. 원래 보고했던
단일 시드값(−0.0103)은 이 분포 안에 있는 전형적인 값이었다.

**4) LightGBM(E) — 트리 개수/복잡도 3단계**(shallow n=50·leaves=7 / default / deep
n=500·leaves=63): delta R²가 −0.0049 ~ −0.0109로 전부 음수, 모델 복잡도를 키워도
UV_type이 양(+)의 기여를 하는 지점은 없었다.

**결론**: 파라미터/옵티마이저/시드를 바꿔도 "Lot을 통제하면 UV_type 효과 없음"이라는
결론은 흔들리지 않았다. 다만 MixedLM 기본 옵티마이저의 수렴 문제는 실제 버그였고,
표의 D행 수치를 정정했다 — 원래는 이 검증 없이 경고가 뜬 결과를 그대로 보고했었다.

## 결론

**4가지 통계 모델 + 1가지 ML 모델, 서로 다른 5가지 방법론이 전부 같은 결론에 수렴한다**:
Lot을 통제하지 않은 나이브 비교(+20.1~8.9%로 이전에 보고했던 수치)는 UV_type의 실제
효과가 아니라 Lot 교란변수의 영향이었다. Lot을 어떤 방식으로든 통제하면 UV_type 효과는
통계적으로 유의하지 않다(p>0.39, 4개 모델 전부). **6절 Executive Summary의 시나리오 B
("H-line→G-line 전환, +0.48%p")는 이번 분석 기준으로는 근거가 없는 것으로 재정정한다.**
