최적 조건 찾기

현재 조건에서 출발해 예측 불량을 가장 크게 줄이는 변수부터 최대 3개만, 실제 데이터의 중심 60% 구간(하위 20%~상위 20%) 안에서 바꿉니다. 모든 변수를 한꺼번에 극단값으로 옮기면 데이터에 없던 조합이 되어 예측을 믿을 수 없기 때문입니다.

모델: LightGBM · 22개 공정 변수 · GroupKFold(Lot) 검증 · 예측·근거 계산은 모두 이 브라우저 안에서 실행됩니다. 예측 기여도는 인과관계가 아니며, 추천 조건은 실제 적용 전 검증이 필요합니다.
